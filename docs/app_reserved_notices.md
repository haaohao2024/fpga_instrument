# App 预留的板端通知（BL616 → App）

App 2.0（iOS 与安卓）已经能接收下面三种通知。现在的 BL616 固件不会发送它们，App 收到前这些功能不显示，也不影响其他功能。以后 BL616 按本文格式发送，App 无需修改即可使用。

所有通知都走现有的通知特征值和消息格式：通道 3，会话号与当前连接一致，序号递增。App 对格式不符的通知直接忽略。

## 133：教学提示（下一个要按的音）

| 字节 | 内容 |
|---|---|
| 0 | 版本，固定为 1 |
| 1 | 音符个数 n（0 表示当前没有提示，App 熄灭提示） |
| 2…1+n | MIDI 音高，第一个是“下一个要按的音”，其余可选（和弦） |

- 发送时机：教学模式下，每当下一个目标音变化时发送一次；曲谱停止或结束时发送 n=0。
- App 表现：对应琴键发光闪烁，键盘自动滚到该音，显示屏显示“教学：请按 X”。当前版本只用第一个音。

## 134：实体琴键状态

| 字节 | 内容 |
|---|---|
| 0 | 版本，固定为 1 |
| 1 | 保留，填 0 |
| 2…17 | 128 位音符位图：第 i 个音（MIDI i）按下时，字节 `2+i/8` 的第 `i%8` 位为 1 |

- 发送时机：实体键按下或松开时发送当前完整状态（不要只发变化量）。
- App 表现：对应虚拟琴键显示为按下（原色加灰）。

## 135：板上当前声音参数

| 字节 | 内容 |
|---|---|
| 0 | 版本，固定为 1 |
| 1 | 音色 0…5 |
| 2 | 释音档位 0…7（沿用 glide_code 通路） |
| 3 | 颤音深度 0…255 |
| 4 | 效果位：bit0 回声、bit1 合唱、bit2 混响、bit3 旁路 |

- 发送时机：实体旋钮改变音色或释音后，以及连接建立后发送一次。
- App 表现：主界面面板按钮和滑条同步为板上的实际值。
